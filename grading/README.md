# 100,000-row grading export

This folder is the grading adapter for the declared 100,000-nonempty-review scope. `run.json` identifies 100,000 selected nonempty reviews plus all 13 empty-text quarantines; `ingestion.json` profiles the full source file. The main classification package was built offline from saved outputs. Two later, bounded TypeSafe requests made the grouping follow-up and next-cycle priority judgments; their input states, choices, confidence, and actual usage are saved here and in `../cost/pilot_calls.jsonl`.

Read `memo.md` for the model-informed recommendation and baseline ranking, `ai_grouping.json` and `ai_recommendation.json` for the two saved Jev judgments, `../cost/review_100000_quality.md` for the human-label and needs-review analysis, and `local_stages.jsonl` for deterministic membership and ranking stages. The model calls did not change baseline membership or ranking. `checkpoint_before.json` is reconstructed from the saved input/cache/call ordering and matches the logged 31,283-record checkpoint; it was not a separately captured snapshot file at runtime.

Known evidence gaps: 12 older failed attempts have unavailable token usage (nine during the 100,000 run and three during earlier checkpoints), preserved as null. The completed bare-`Boycott` labels also remain as produced and are documented in the quality review. The new grouping and memo role calls succeeded with complete usage.
